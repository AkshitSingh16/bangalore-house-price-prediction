# bangalore-house-price-prediction

## Project Overview
- Developed a Machine Learning web application to predict house prices in Bangalore based on factors such as location, total square feet area, number of bedrooms (BHK), and bathrooms.

## Technologies Used
- Python
- Pandas & NumPy
- Scikit-Learn
- Flask
- HTML, CSS, Bootstrap

## Features
- Data cleaning and preprocessing of Bangalore housing dataset.
- Trained and evaluated regression models for accurate price prediction.
- Interactive web interface for user input and real-time predictions.
- Location-based house price estimation using a trained machine learning model.

## Model Performance
- Applied regression techniques and selected the best-performing model based on R² score and prediction accuracy.

## Future Enhancements
- Add more location data and advanced ML models.
- Deploy the application on cloud platforms such as Render or Heroku.
- Improve UI and include graphical analytics for better user experience.
